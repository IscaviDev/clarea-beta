# Clarea Beta

La web montada de Clarea (https://beta.clarea.dev/): una app instalable para organizar los estudios de cualquier curso.
No se edita a mano: se monta desde el código fuente con `npm run build` -- --mode beta.

## Instalar en el iPhone
1. Abre la página en **Safari**.
2. **Compartir → Añadir a pantalla de inicio**, con «Abrir como app web» activado.
3. Abre Clarea desde el icono y entra con tu cuenta.
