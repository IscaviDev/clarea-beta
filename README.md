# Clarea

App personal de estudio para DAW2 (funciona sin internet): asignaturas, horario, faltas de asistencia y el repaso del proyecto PJ6.

## Instalar en el iPhone
1. Abre la página en **Safari** (con internet, solo la primera vez).
2. **Compartir → Añadir a pantalla de inicio**, con «Abrir como app web» activado.
3. Abre Clarea desde el icono y crea tu cuenta.

Las cuentas y los datos se guardan solo en el dispositivo. Para pasarlos a otro, usa **Exportar / Importar progreso** en el menú de la cuenta.
